# تبسيط القائمة الرئيسية — الحصر والتنفيذ (2026-11-01)

## مصدر القائمة (من الشيفرة)

| الملف | الدور |
|---|---|
| `NavigationRegistry` | القائمة المعتمدة: الصفحة، والمسار، وقاعدة الظهور |
| `navigation_items` | العرض (الاسم، الأيقونة، المجموعة، الترتيب، الإخفاء)، ويحرره مدير النظام من «القائمة الرئيسية» |
| `NavigationBuilder` | يبني قائمة المستخدم بقواعد `NavigationAccessRules` نفسها التي تحمي الصفحات |
| `NavigationPriorities` | ترتيب العرض حسب سياق العمل |
| `AppLayout.vue` | الشريط الجانبي، ودرج الجوال، والبحث في القائمة |

- البوابة لها قائمتها المستقلة (`PortalLayout`: خمسة أقسام)، ولم تُمس.
- قبل التنفيذ، طابقت قاعدة البيانات السجل تمامًا (لا تخصيصات من مدير النظام)، فإعادة الضبط لم تُضيّع أي تخصيص.

## المشكلات التي وُجدت
1. **الحسابات في 6 مجموعات** (قسم الحسابات، المشتريات، المخازن، المحاسبة والتحصيل، الرواتب، الموازنات) بـ27 رابطًا. كلها أقسام لصفحة واحدة (`/finance?view=…`) لها تنقلها الداخلي «أقسام الحسابات».
2. **مجموعة «الحضور والانصراف»** فيها رابط بالاسم نفسه. كانت تُنشأ صناعيًا في `NavigationPriorities::attendanceGroup`، فتنفصل عن «الدوام والإجازات».
3. **«طلباتي» تعرض كل نوع طلب رابطًا مستقلًا** (شكوى، خدمة، سلفة، صيانة، إجازة)، مع أن صفحة «طلباتي» فيها لوحة «طلب جديد» بالأنواع نفسها.
4. **سبعة روابط شخصية وإدارية في المستوى الأول.**
5. **أيقونة لكل رابط فرعي.**
6. **أكثر من مجموعة مفتوحة في الوقت نفسه.**

## الخريطة: القديم ← الجديد

| القديم | الإجراء | الجديد |
|---|---|---|
| مساحتي، مهامي، المراسلات الرسمية | Keep | المستوى الأول |
| مهامي الشخصية، ملفي الوظيفي | Merge | «خدماتي» |
| مجموعة «طلباتي» ← جميع طلباتي | Merge | «خدماتي ← طلباتي» |
| طلب إجازة، أنواع الطلبات المفعلة، مسودة صيانة | Move to page action | «طلباتي ← طلب جديد» و«مساحتي» (مخفية افتراضيًا) |
| مجموعة «الدوام والإجازات» ← الإجازات والموافقات، أرصدة الإجازات | Merge | «خدماتي» |
| الحضور والانصراف، العطل والعمل التعويضي، عمليات الأجهزة | Merge | «الموارد البشرية» (أُلغيت المجموعة الصناعية المكررة) |
| مجموعة «الموظفون» | Keep (إعادة تسمية) | «الموارد البشرية» |
| استيراد الموظفين | Move to page action | زر في «ملفات الموظفين» |
| قسمي، مؤشرات الأداء، التفويضات الإدارية، الهيكل التنظيمي | Merge | «الإدارة والمتابعة» (تظهر لمن تسمح له قواعده فقط) |
| 6 مجموعات للحسابات / 27 رابطًا | Merge + Move to tabs | «الحسابات»: بانتظار إجرائي، **أقسام الحسابات** (`/finance` يفتح أول قسم مسموح)، صندوق الاعتمادات، قبض الإيجارات، التقارير. البقية أقسام داخل الصفحة (مخفية افتراضيًا) |
| الأصول والإيجارات | Keep (إعادة تسمية) | «الأصول والمباني والإيجارات» |
| شؤون الأيتام والكفالات (6) | Keep | كما هي. الاستيراد الذكي و«إضافة جديد» إجراءات داخل الصفحات |
| الإعدادات والصلاحيات (16) | Keep | لمدير النظام فقط. إعدادات الأيتام فيها بقرار سابق |

- **العرض:** الأيقونات للمستوى الأول فقط، والروابط الفرعية نص. مجموعة واحدة مفتوحة، مع بقاء مجموعة الصفحة الحالية مفتوحة.
- **الإزالة:** لم يُحذف مسار ولا صفحة ولا صلاحية.
- **الإخفاء:** الروابط المخفية باقية في محرر «القائمة الرئيسية»، ويمكن إظهارها.
- **المجموعات الست المدمجة:** حُذفت صفوفها بعد خلوها، وسُجل ذلك في التدقيق (`RETIRED`).
