# نظام التصميم — الرموز والمكونات الفعلية

## الرموز (`resources/css/aims.css`، مأخوذة من الشعار)

**الألوان:**
- `navy` #324F7C: النص والعناوين.
- `blue` #117EC2: لون الإجراء الوحيد، ويحل محل أزرق Tailwind.
- `gold` #E0BB4D: التنبيه والتمييز.
- `canvas` #F5F7FA: الخلفية.
- الحالات: emerald (نجاح)، gold (تنبيه)، red (خطر)، slate (محايد).

**الخطوط:**
- `--font-sans`: IBM Plex Sans Arabic (ملفات محلية في `public/fonts`).
- `--font-display`: Noto Kufi Arabic.

**الأرقام:**
- لاتينية داخل نص عربي (`ar-u-nu-latn`) مع فواصل الآلاف.
- `tabular-nums` في المؤشرات.

**الحركة والوصول:**
- `prefers-reduced-motion` مدعوم.
- حلقات تركيز ظاهرة.
- أهداف لمس 44px على الشاشات اللمسية.

## مكونات اللوحات (`resources/js/Components/Dashboard/`)

| المكون | الاستخدام |
|---|---|
| `RoleBoards` | تبويبات حين يحمل المستخدم أكثر من دور. التنقل بالأسهم باتجاه RTL، والتبويب المختار يُحفظ محليًا. اللوحة الفاشلة تُعرض بحالة خطأ مع إعادة محاولة |
| `RoleBoard` | سؤال القرار والنطاق ووقت التحديث. المؤشر الرئيسي أولًا (أعلى اليمين) ثم 2–3 مؤشرات، ثم خط زمني بعرض الثلثين بجانب أعمدة الثلث، ثم الجدول، ثم «تعريف المؤشرات» |
| `MetricCard` | القيمة. المقارنة بكلمات وسهم: أعلى/أقل، تحسن/يحتاج انتباهًا بحسب `better`. «لا تتوفر بيانات مقارنة» حين لا مقارنة، و«غير متاح» مع السبب حين لا مصدر |
| `TrendChart` | خط SVG بنوافذ 7 أيام × 12. الأقدم يمينًا. السلاسل تختلف باللون ونمط الخط. تلميح أصلي لكل أسبوع، وجدول بديل، و`aria-label` يلخص آخر أسبوع. لا خط عند غياب الحركة |
| `CategoryBarChart` | أعمدة أفقية بلون واحد، والقيمة مكتوبة بجانب كل عمود. الصف رابط إلى السجل المصفّى حين يوجد |
| `ActionTable` | بحث، «المتأخرة فقط»، فرز بالأعمدة (`aria-sort`)، صفحات من 10. «لا توجد نتائج مطابقة للفلاتر» مع مسح الفلاتر. بطاقات على الجوال (`aims-responsive-table`) |
| `BoardSkeleton` | هيكل مؤقت بنفس التخطيط، فلا يظهر صفر كأنه بيانات |
| `Portal/RequestTimeline` | مراحل طلب الأسرة في البوابة: مسودة ← تقديم ← مراجعة أو استكمال ← قرار، بنص لا يعتمد على اللون |

## مكونات قائمة يُعاد استخدامها
`PageHeader`، `StatusBadge`، `EmptyState`، `AppDialog`، `RecordPreview`، `FormSteps`، `FormErrorSummary`، `Pagination`، `ActiveFilters`، `AppIcon`، `Registry/ImportIcon`.

## الخادم (`app/Services/Dashboard/`)

**`RoleBoards::plan/for/orphans`:**
- يختار اللوحات من قواعد الصلاحية نفسها التي تستخدمها الوحدات.
- كل لوحة تُبنى في `try`؛ فشل لوحة لا يُسقط الصفحة.

**`Boards/BoardKit`:**
- `metric`، `weekOverWeek` (7 أيام مقابل الـ7 السابقة)، `weekly` (12 نافذة)، `trend`، `bars`، `table`.

**اللوحات:**
- `ExecutiveBoard`، `DepartmentHeadBoard`، `OrphansBoards`، `ServiceBoards`: الموارد البشرية، والحسابات، والإيجارات، ومدير النظام، والموظف.

**التحميل:** خاصية `boards` مؤجلة (`Inertia::defer`)، تُحمّل بعد الصفحة في `Home` و`Orphans/Home`.
