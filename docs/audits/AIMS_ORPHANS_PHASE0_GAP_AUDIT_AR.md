## 5. تعارضات تحتاج حسمًا

1. **التسجيل (س04 مع قرار 22/10، البند 3):** القرار السابق يوقف أي اعتماد حتى تتوفر خدمة السجل المدني. الوثيقة الجديدة تقبل الإدخال الأولي «بانتظار التحقق» وهذا متوافق، لكن من دون خدمة أو تحقق يدوي لن يُعتمد أي ملف أبدًا. **القرار المطلوب:** هل يُفعَّل التحقق اليدوي بالوثائق؟ الإعداد موجود ومعطل.
2. **النسخ الاحتياطي (المرحلة 0 مع قرار 22/10، البند 1):** الوثيقة تشترط نسخة قابلة للاستعادة، وقد أُخذت. أما «اختبار الاستعادة» الكامل فيحتاج قاعدة مؤقتة، وتعليماتك تمنع قواعد الاختبار. **القرار المطلوب:** السماح بقاعدة مؤقتة تُحذف بعد الاختبار، أو الاكتفاء بالتحقق الحالي.

## 7. قرارات القسم 8 المطلوبة قبل أي ترحيل جديد

1. **الواجهة الحكومية:** الجهة، والتوثيق، والمصادقة، والحدود، وشكل الأخطاء. أو قرار التحقق اليدوي (البند 5.1).
2. **الاستحقاق:** تعريف بيانات الاستحقاق ودرجات اليتم والناجي الوحيد بمعرّفات وأوزان، وإعادة إرسال «معيار الإنصاف V1».
3. **المحلي/VPS:** من يملك كتابة كل نوع سجل، واتجاه المزامنة، والمدة المقبولة للانقطاع.
4. **الحسابات والمخزون:** طريقة ربط المساعدة بالتسوية المالية والعينية، والعهدة لكل كشف.
5. **حماية البيانات:** مدد الاحتفاظ لكل فئة بيانات، وموافقة الاتصال، وحماية بيانات الأطفال.
6. **التفويض القانوني:** النموذج المقبول، والهوية البديلة عند غياب البطاقة.
