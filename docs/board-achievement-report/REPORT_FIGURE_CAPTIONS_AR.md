# تعليقات الأشكال (جاهزة للنسخ)

**الشكل 1:** لوحة الموارد البشرية والخدمات العامة: متابعة يومية لعدد الموظفين والحضور والإجازات وطلبات الخدمات، مع قائمة بما يحتاج إجراء. (حُجبت الأسماء)

**الشكل 2:** سجل الحضور والانصراف المرتبط بجهاز البصمة: مزامنة آلية وحساب يومي لحالة الالتزام لكل موظف. (حُجبت الأسماء)

**الشكل 3:** تقارير سجل الأيتام: 37,542 ملفًا في سجل موحد، مع توزيع عمري وجغرافي. الملفات المستوردة «معتمدة مبدئيًا»، وتخضع للتحقق قبل أي اعتماد قانوني أو كفالة.

**الشكل 4:** الاستيراد الذكي لبيانات الأيتام: فحص 62,597 صفًا وتصنيفها جاهزًا أو يحتاج مراجعة أو متعارضًا، قبل إدراجها في السجل.

**الشكل 5:** الهيكل التنظيمي المعتمد: المكاتب والأقسام والوحدات الوظيفية، ولا يُطبق أي تعديل إلا باعتماد المدير التنفيذي. (حُجب الاسم)

**الشكل 6:** مؤشرات الأداء: تُحسب من السجلات الفعلية بشفافية (البسط والمقام وحجم العينة). الأهداف لم تُعتمد بعد.
