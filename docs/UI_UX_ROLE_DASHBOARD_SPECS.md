# مواصفات لوحات الأدوار (كما نُفذت)

## قواعد مشتركة

**المقارنة:**
- «آخر 7 أيام مقابل السبعة السابقة» لمقياس التدفق المذكور في نص البطاقة.
- لا تُرسم مقارنة إن لم يكن لها مصدر.

**الخط الزمني:**
- 12 نافذة أسبوعية (7 أيام) تنتهي اليوم.
- الصفر قيمة حقيقية.
- لا حركة طوال المدة = رسالة «لا توجد حركة» بدل الرسم.

**الحالات:**
- تحميل: هيكل مؤقت.
- فارغ: نص.
- فلتر فارغ: مسح الفلاتر.
- غير متاح: سبب.
- خطأ لوحة: إعادة محاولة.
- غير مصرح: الخادم يرفض (403) ولا يبني اللوحة أصلًا.

**العد:**
- الأيتام: طفل واحد لكل ملف.
- الكفالات: أيتام دون تكرار.
- التسليم: كميات مؤكدة غير مصححة.
