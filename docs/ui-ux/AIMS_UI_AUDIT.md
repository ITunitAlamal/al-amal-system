**المصدر:** فحص الشيفرة والقاعدة الحية للقراءة فقط (`ux_baseline.php`). البيانات التفصيلية للجولة السابقة في `docs/UI_UX_SCREEN_INVENTORY.md` و`docs/AIMS_NAVIGATION_AUDIT.md`.

## 1. التقنية الفعلية
- Laravel 13 + Inertia 3 + Vue 3.5 + Tailwind 4، وPostgreSQL 18.
- البوابة صدفة منفصلة (`/guardian`، `PortalLayout`)، لا تشارك القائمة الجانبية.
- **الهوية البصرية:** `resources/css/aims.css`، مأخوذة من الشعار.
  - الألوان: كحلي `#324F7C`، وأزرق `#117EC2`، وذهبي `#E0BB4D`.
  - الخطوط: IBM Plex Sans Arabic للنص، وNoto Kufi Arabic للعناوين، وكلاهما مستضاف محليًا.
- لا وضع داكن؛ الوضع الفاتح هو المعتمد.
- عدد المسارات المسجلة: 574.

## 4. ما وُجد قائمًا (لا يُعاد بناؤه)
- **الصدفة:** رابط «تجاوز القائمة»، وقائمة قابلة للطي، ودرج للجوال (`role=dialog`، مع حبس التركيز)، وبحث موحد (`QuickSearch`)، وجرس الإشعارات والبريد، واختصار «مهامي».
- **إمكانية الوصول:** مؤشر التركيز `:focus-visible`، واحترام `prefers-reduced-motion`.
- **لوحات الأدوار:** لكل دور سؤال قرار ورقم رئيسي ومؤشرات واتجاه 12 أسبوعًا وتوزيع وجدول إجراءات (التفاصيل في `AIMS_ROLE_DASHBOARDS.md`).
- **جداول اللوحات:** تتحول إلى بطاقات على الجوال (`aims-responsive-table`).

## 5. مواضع الخلل
**أُصلحت في هذه الجولة:**

| الخلل | الإصلاح |
|---|---|
| لا مسار صفحة («أين أنا؟») في الصدفة | مسار «القسم ‹ الصفحة» من القائمة نفسها، فلا يظهر اسم صفحة لا يملكها المستخدم |
| المدير التنفيذي يرى لوحتين متداخلتين (لوحته ولوحة «المكتب التنفيذي») | اللوحة التنفيذية تغطي المكتب |
| لوحة مدير النظام آخر التبويبات بعد لوحتي الموارد والإيجارات | تفتح أولًا |

**باقية:**
- لوحة رئيس الأيتام تُبنى في 1.1 ثانية، ولوحات مدير النظام في 1.5 ثانية. التحميل مؤجل، لكن يُستحسن تخزينها مؤقتًا لاحقًا.
- قوائم الصفحات الطويلة (غير اللوحات) تعتمد التمرير الأفقي على الجوال، لا البطاقات.
- لا مكوّن موحد لـ«لوحة التوزيع» (`AssignmentBoard`) ولا لـ«المساعدة السياقية» (`InlineHelp`).
- لا حفظ للمرشحات بين الجلسات.

## 6. حالة الاختبارات
- PHPUnit واختبارات الواجهة لا تُشغَّل، بقرار المالك.
- التحقق نصي على النظام الحي: سكربتات في معاملات تُلغى، وطلبات HTTP بأدوار حقيقية، و`npm run build`، و`pint`.
- لا لقطات شاشة ولا متصفح آلي، بقرار المالك، فلم يُفحص العرض البصري على الجوال.
