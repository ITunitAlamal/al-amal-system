# تقرير التنفيذ — جولة «واجهة بسيطة لكل الموظفين» (2026-11-01)

## ما كان منفذًا قبل الجولة (لم يُعَد)
- **لوحات الأدوار:** للمدير التنفيذي، وخمسة اختصاصات أيتام، والموارد البشرية، والحسابات، والإيجارات، ورؤساء الأقسام، ومدير النظام، والموظف.
- **البوابة:** صفحاتها الثمانية الناقصة.
- **تبسيط القائمة:** المستوى الأول 17 ← 10 لمدير النظام، و7 ← 4 للموظف. الأقسام الستة للأيتام محفوظة.
- **«سجل النظام»** و«سجل التغييرات» السياقي.
- **لوحات وحدات الحسابات،** و«موظفو القسم وصلاحياتهم»، و«طلب قسيمة راتب» في «طلباتي».

## تغييرات هذه الجولة
| الملف | التغيير |
|---|---|
| `resources/js/Layouts/AppLayout.vue` | مسار الصفحة «القسم ‹ الصفحة» في الشريط العلوي، من القائمة المصرّح بها نفسها (`nav aria-label="مسار الصفحة"`) |
| `app/Services/Dashboard/Boards/DepartmentHeadBoard.php` | المكتب التنفيذي تغطيه لوحة المدير التنفيذي؛ لا لوحة ثانية متداخلة |
| `app/Services/Dashboard/RoleBoards.php` | لوحة مدير النظام تفتح أولًا |
| `docs/ui-ux/*.md` | التدقيق، ونظام التصميم، ولوحات الأدوار، وهذا التقرير |

## التحقق الفعلي
- **خط الأساس:** `ux_baseline.php` للقراءة فقط، على 11 مستخدمًا حقيقيًا بأدوار مختلفة.
  - القائمة لا تتجاوز مستويين.
  - صفحات «مهامي» و«طلباتي» تعيد 200 لكل الأدوار، في 245–420ms على الخادم.
  - اللوحات تُبنى دون خطأ، وبعد التعديل: مدير النظام `sysadmin` أولًا، والمدير التنفيذي `executive` وحدها.
- `php -l` و`pint` (passed) و`npm run build` (نجح).
- **لم يُشغَّل:** PHPUnit واختبارات الواجهة.
- **لم يُصوَّر:** لا لقطات شاشة، بقرار المالك.

## القيود والمراحل التالية المقترحة (لم تُنفذ)
1. **قوائم الصفحات الطويلة:** بطاقات على الجوال بدل التمرير الأفقي. يلزم تعديل كل جدول على حدة، لأن أعمدتها مختلفة.
2. **`AssignmentBoard`** لرؤساء الأقسام: توزيع المهام حسب الموظف، والمتأخر، وإعادة الإسناد. يحتاج قرارًا: هل يعيد الرئيس إسناد مراحل مسار العمل، أم المهام الشخصية فقط؟
3. **`InlineHelp`** موحد لمصطلحات الحسابات والأيتام والوصاية.
4. **حفظ المرشحات** بين الجلسات، و«آخر ما فتحت».
5. **تخزين مؤقت** للوحتي رئيس الأيتام ومدير النظام (1.1 و1.5 ثانية).
6. **موحِّد رفع المستندات** بدل ثلاثة مكونات.
