# لوحات الأدوار (`App\Services\Dashboard\RoleBoards`)

## كيف تعمل
- **مكانها:** تظهر في «مساحتي» (لوحات الأيتام أيضًا في «الرئيسية» للقسم)، تبويبًا لكل لوحة.
- **محتوى كل لوحة:** سؤال القرار، ورقم رئيسي في أعلى اليمين، و2–3 مؤشرات، واتجاه 12 أسبوعًا (الثلثان)، وتوزيع (الثلث)، وجدول «يحتاج إلى إجراء» بروابط إلى السجلات المصفاة نفسها.
- **مصدر الأرقام:** استعلامات حقيقية بنطاق صلاحية المستخدم. ما لا مصدر له يظهر «غير متاح» مع السبب.
- **عند الفشل:** تفشل اللوحة وحدها، وتبقى الصفحة.
- **من يرى أي لوحة** (`RoleBoards::plan`):

| الحالة | اللوحات |
|---|---|
| مدير النظام | لوحته أولًا، ثم لوحات الإدارة التي تخوّله صلاحيته التقنية رؤيتها |
| المدير التنفيذي | لوحته، وتغطي مكتبه |
| الأيتام | لوحة لكل اختصاص |
| الموارد البشرية | لمن يدير الموظفين |
| الحسابات | صندوق الاعتمادات للمعتمدين، ولوحة لكل وحدة يعمل فيها الموظف |
| الإيجارات | لموظف الإيجارات |
| رؤساء الأقسام الأخرى | لوحة القسم |
| غيرهم | «مهامي» |

## القرار والرقم الرئيسي لكل لوحة
| اللوحة | السؤال | الرقم الرئيسي | الجدول والانتقال |
|---|---|---|---|
| المدير التنفيذي | أين يلزم قراري الآن، وأي أعمال المؤسسة متأخرة؟ | قرارات تنتظر اعتمادي الآن (مقارنة بالأسبوع السابق) | كشوف الحملات الأولية والمعدّلة (اعتمادها حصري له)، والمهام، وطلبات الصلاحيات المالية الحساسة → `/tasks`، صفحة الكشف |
| متابعة الحسابات (رئيس القسم) | أين يتعطل العمل بين وحدات القسم؟ | معاملات تنتظر إجراءً في الوحدات | أقدم طلبات الشراء دون أمر، والعمل المعلق حسب الوحدة. **اطلاع فقط** |
| المشتريات | أي الطلبات المعتمدة تحتاج عروضًا وأمر شراء؟ | طلبات معتمدة دون أمر شراء | لا أرقام مخازن ولا رواتب |
| المخازن | ما الذي ينتظر استلامًا فعليًا، وما تحت الحد الأدنى؟ | أوامر بانتظار الاستلام | لا صرف ولا اعتماد شراء |
| الفواتير وسندات الصرف | أي المستلم يحتاج فاتورة، وأي فاتورة تنتظر السند؟ | فواتير بانتظار سند الصرف | أرصدة البنوك «غير متاحة» (الدفاتر خارجية) |
| الرواتب والقسائم | أي مسير يحتاج إدخالًا أو نشرًا؟ | طلبات قسائم بانتظار المسير | المسير المنشور منفصل عن المسجَّل |
| صندوق الاعتمادات المالية | أي الاعتمادات تحتاج إجرائي؟ | اعتمادات بانتظاري | — |
| شؤون الأيتام (الرئيس) | أي الطلبات والملفات والكفالات تحتاج إجراء الفريق؟ | الأيتام المسجلون (طفل واحد لكل ملف)، و«معتمد مبدئيًا» منفصلًا | — |
| التسجيل والمراجعة | أي حالة أعالجها الآن؟ | حالات مسندة إليّ تحتاج إجراء | إجراء رئيسي: «تسجيل أسرة» |
| البحث الاجتماعي | أي الزيارات أبدأ بها؟ | زيارات وتقييمات متأخرة | — |
| الكفالات | أي الكفالات تحتاج متابعة؟ | أيتام مكفولون حاليًا (دون تكرار) | — |
| الحملات الإغاثية | هل يمكن تنفيذ الحملة المعتمدة بدقة وفي موعدها؟ | مخصصات معتمدة بانتظار تسليم مؤكد | الترشيح ≠ التسليم |
| الموارد البشرية | أي مسائل الإجازات والدوام تحتاج إجراء؟ | طلبات إجازة معلقة | لا رواتب الزملاء |
| الأصول والإيجارات | أي العقود والاستحقاقات والصيانة تحتاج إجراء؟ | عقود تنتهي قريبًا دون تجديد | — |
| رئيس قسم (عام) | ما حال طلبات قسمي؟ | طلبات القسم الجارية | — |
| مدير النظام | هل توجد أعطال تقنية أو نواقص إعداد؟ | أعطال تقنية تحتاج متابعة | لا بيانات مستفيدين، ولا صلاحية اعتماد |
| الموظف | ما الذي أنجزه اليوم؟ | مهامي اليوم | — |

**المصادر:** `Boards/ExecutiveBoard`، و`OrphansBoards`، و`ServiceBoards`، و`FinanceUnitBoards`، و`DepartmentHeadBoard`. تعريف كل مؤشر يظهر بجانبه في الواجهة.

**بوابة المستفيدين:** صدفة مستقلة بخمس مجموعات. لم تتغير في هذه الجولة؛ انظر `docs/UI_UX_ROLE_DASHBOARD_SPECS.md`.
