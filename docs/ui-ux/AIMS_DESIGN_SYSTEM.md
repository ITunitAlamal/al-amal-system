# نظام التصميم (المعتمد فعلًا في الشيفرة)

**مصدر الحقيقة:** `resources/css/aims.css`. التفاصيل السابقة في `docs/UI_UX_DESIGN_SYSTEM.md`. لا مكتبة تصميم ثانية.

## الرموز (tokens)
- **الألوان من الشعار** (تدرّجات Tailwind 50–950):
  - `navy`: الأساسي، 700 = `#324F7C`.
  - `blue`: الإجراء والروابط، 600 = `#117EC2`.
  - `gold`: التنبيه والتمييز، الشمس `#E0BB4D`.
- **ألوان الحالة الدلالية فقط:**
  - `success`: أخضر.
  - `warning`: ذهبي.
  - `danger`: أحمر.
  - `info`: أزرق.
  - `muted`: رمادي.
  - كل حالة نص مع اللون، لا لون وحده (`StatusBadge`).
- **الخط:**
  - `--font-sans` (IBM Plex Sans Arabic، الأوزان 400–700) للنص.
  - `--font-display` (Noto Kufi Arabic) للعناوين.
  - النص الأساسي 14–16px، والجداول 14px، والتلميحات 12px.
- **المسافات:** إيقاع Tailwind (4px). البطاقة `.card` بحشوة 20–24px، وحواف `rounded-2xl`، وظل خفيف.
- **التركيز:** إطار أزرق 2px على `:focus-visible`، وذهبي داخل القائمة الداكنة.
- **الحركة:** تُعطَّل مع `prefers-reduced-motion`.

## قواعد
- **الأيقونات:** مجموعة واحدة (`Support/menuIcons.js`)، ولكل أيقونة نص ظاهر. أيقونات المجموعات في القائمة فقط، ولا أيقونات للروابط الفرعية.
- **إجراء رئيسي واحد في كل صفحة،** والنادر في قائمة «المزيد» أو داخل الدرج.
- **الرسوم:**
  - خط زمني للاتجاه (12 أسبوعًا) بثلثي العرض، وأعمدة للمقارنة بثلثه.
  - لا دوائر ولا ثلاثي الأبعاد.
  - لكل رسم بديل نصي، وحالة «لا بيانات كافية» صريحة.
- **الاتجاه:** RTL في كل الصفحات. الأرقام والمراجع `dir="ltr"` داخل النص العربي. محور الزمن معكوس ليقرأ من اليمين.
- **التجاوب:**
  - القائمة درج تحت `lg`.
  - جداول اللوحات بطاقات تحت `sm`.
  - النماذج عمود واحد على الجوال.
- **الحالات:** لا تُدمج الحالات المختلفة.
  - «معتمد مبدئيًا» ≠ «معتمد».
  - الترشيح ≠ التسليم.
  - المسير المنشور ≠ المسجَّل.
  - الوصاية المدّعاة ≠ المتحقق منها.
