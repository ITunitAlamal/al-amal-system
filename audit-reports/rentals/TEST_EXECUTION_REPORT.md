# تقرير تنفيذ الاختبارات: ملف الأصول والإيجارات (2026-10-23)

## الطريقة

- طلبات HTTP فعلية عبر نواة Laravel على القاعدة الحقيقية `al_amal_db`، بحسابات حقيقية:
  - رئيس قسم الأصول (u11)؛
  - المدير التنفيذي (u6)؛
  - رئيس الحسابات (u5)، وأُسند له مؤقتًا دور محاسب وتخصيص مالي داخل المعاملة؛
  - رئيس الموارد البشرية (u2)؛
  - مدير النظام (u1)؛
  - موظف (u7).
- **عزل الكتابات:** كل شيء داخل معاملة واحدة أُلغيت (rollback) في النهاية.
  - حُذفت الملفات المرفوعة.
  - أُعيدت كل المتسلسلات المتأثرة (28) إلى قيمها السابقة.
  - بعد الفحص: 0 سجل إيجار، 0 ملف، ولا فجوة في الأرقام.
- **بيانات الفحص** (داخل المعاملة وأُلغيت):
  - اسم مبنى في الثوابت؛
  - مستأجر بمعرّف `E2E-REG-1`.
  - لم يُستخدم أي مستأجر حقيقي.
- **ما لم يُشغَّل:** `php artisan test` وملفات الاختبار ممنوعة بتعليمات المالك، ولا يوجد مجلد `tests`. الأداة: سكربت تحقق مؤقت خارج المشروع.
