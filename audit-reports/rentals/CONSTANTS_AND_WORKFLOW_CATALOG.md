# الثوابت ومسارات العمل: ملف الأصول والإيجارات

## الثوابت المركزية (مجموعة «ثوابت الأصول والإيجارات»)

القيم تُدار من «الثوابت». لا توجد قائمة موازية داخل الوحدة.

| النوع | الاستخدام | القيم الأولية ومصدرها |
|---|---|---|
| `asset_types` أنواع الأصول | نوع الأصل | أراضٍ، مبانٍ، مرافق عقارية تشغيلية، مرافق عقارية استثمارية (الحزمة §A) |
| `property_ownership_types` | ملكية الأصل | فارغة: يضيفها مدير النظام |
| `rental_unit_types` و`rental_unit_usages` | نوع العين واستخدامها | فارغة: يضيفها مدير النظام |
| `rental_services` | خدمات العقد | الكهرباء، الإنترنت، اللوحة الإعلانية، تأجير مساحة على السطح (الوثيقة §5 و§7) |
| `rental_document_types` | تصنيف المستندات | الهوية، تسجيل المؤسسة، التفويض، المراجع، المخططات، العقد الموقع، محضر التسليم، محضر الاستلام والإخلاء، محضر الفحص، صور العداد، المخالصة، مستند آخر (الوثيقة) |
| `rental_settlement_types` | نوع التسوية | سبعة أنواع من الحزمة §4 |
| `rental_termination_reasons` | سبب الإنهاء | عدم التجديد عند انتهاء المدة، طلب المستأجر الإخلاء (الوثيقة §8 و§9) |
| `payment_methods` (قائم) | طريقة الدفع في سند القبض | فارغة حاليًا |
| ثوابت المباني والمرافق (قائمة) | أسماء المباني | **فارغة:** لا يمكن تسجيل أي أصل قبل إضافتها |

**إعدادات** `rentals_module_settings` (يضبطها مدير النظام من تبويب الملخص):
- التنبيه قبل الانتهاء: 90 يومًا افتراضيًا (الوثيقة §8).
- تنبيه التأخر بعد موعد الاستحقاق: 0 أيام.

**أحداث الإشعار** (من «إعدادات الإشعارات»):
- `rental_contract_expiring`؛
- `rental_contract_expired`؛
- `rental_due_overdue`.

## مسارات العمل

كل المسارات على المحرك المركزي، منشورة بالإصدار 1. كل طلب يحتفظ بالإصدار الذي بدأ به.

| الرمز | المراحل | القرار النهائي |
|---|---|---|
| `RENTAL_APPLICATION` (RAP) | دراسة مسؤول الملف ← قرار المدير التنفيذي: قبول، أو استكمال، أو قائمة انتظار، أو رفض مسبب. من قائمة الانتظار: إعادة رفع أو إغلاق | المدير التنفيذي |
| `RENTAL_CONTRACT` (RCT) | إعداد العقد ← اعتماد المدير التنفيذي ← التوقيع والتسليم ثم التفعيل (أو إلغاء مسبب) | المدير التنفيذي؛ التفعيل لمسؤول الملف بعد العقد الموقع ومحضر التسليم |
| `RENTAL_TERMINATION` (RTM) | الطلب ← الفحص (رئيس الموارد البشرية والخدمات العامة، والبديل المدير التنفيذي) ← مخالصة الحسابات ← قرار المدير التنفيذي ← محضر الاستلام | المدير التنفيذي |
| `RENTAL_SETTLEMENT` (RST) | الطلب ← مراجعة الحسابات وتوصيتها ← قرار المدير التنفيذي ← تسجيل الترحيل من البرنامج المحاسبي | المدير التنفيذي؛ الأثر المالي عند الترحيل فقط |

**ضوابط المسارات:**
- **الفصل بين الواجبات:** مقدم الطلب لا يقرر في طلبه، والمحرك يستثنيه من المراحل التالية. اختُبر: مسؤول الملف لا يرى «قبول» على طلبه.
- **أسباب إلزامية:** الإعادة والرفض وقائمة الانتظار والإلغاء والفحص والمخالصة والتوصية.
- **الحالة لا تسبق التنفيذ:** لا يظهر الطلب «مكتملًا» قبل التنفيذ. العقد لا يصبح «فعالًا» قبل التفعيل الفعلي، والتسوية لا تصبح «مُرحّلة» قبل تسجيل رقم القيد.
- **التعديل بإصدار جديد:** تعديل أي مسار يتم بإصدار جديد من «مصمم المسارات»، ويُستكمل الطلب القائم على إصداره.
